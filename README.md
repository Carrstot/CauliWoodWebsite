# Cauli Wood Gallery Website

A single-page gallery layout created as a web development course project using HTML and CSS.

## Live Demo

[View the website](https://carrstot.github.io/CauliWoodWebsite/)

## Project Overview

This project was completed in February 2023 as part of my web development coursework. It demonstrates HTML page structure, CSS styling, navigation design, image layouts, Flexbox, and responsive formatting for mobile and larger screens.

The assignment focused on designing a single webpage, so the navigation and event links are placeholders rather than links to additional pages.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Responsive web design
- CSS media queries

## Project Status

This repository preserves the original course project. The homepage was renamed from `cw_home.html` to `index.html` so it could be displayed through GitHub Pages.
